# Как выложить сайт «Вершина» на Vercel — без терминала, за 10 минут Никаких VPS, Docker или командной строки — всё делается мышкой в браузере. --- ## Важное честное уточнение Вы написали, что связали Vercel с Claude — это так, я вижу ваш аккаунт Vercel, но инструмент, который мне для этого дали, **умеет только смотреть** существующие проекты и деплои (для отладки), а не создавать новые или заливать код. Поэтому сам процесс публикации нужно один раз пройти вам самим в браузере — это буквально пара кликов, описываю по шагам ниже. --- ## Что изменилось по сравнению с прошлой версией Убрал всё, что требовало сервера: Docker, базу данных SQLite, отдельную админку с паролем. Теперь это просто: - 4 HTML-страницы + `styles.css` + `app.js` — как раньше - Одна маленькая serverless-функция `api/request.js`, которая при отправке формы пересылает заявку **вам в Telegram** Никакой базы данных нет — история заявок хранится прямо в переписке с вашим Telegram-ботом (это и есть ваша «админка»: прокрутили чат — увидели все заявки с датой и временем). Если вам позже понадобится полноценная админка со статусами и историей — это можно добавить отдельно (Vercel Postgres), но для старта этого достаточно и в разы проще. --- ## Шаг 1. Создайте Telegram-бота для приёма заявок (2 минуты) 1. В Telegram найдите **@BotFather**, отправьте ему `/newbot`, придумайте имя. 2. Он выдаст **токен** вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохраните его. 3. Напишите **своему новому боту** любое сообщение (например, «привет») — иначе он не сможет писать вам первым. 4. Откройте в браузере (замените токен на свой): `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` 5. В открывшемся тексте найдите `"chat":{"id":123456789,...}` — число после `"id":` — это ваш **chat id**. Сохраните и его. --- ## Шаг 2. Загрузите проект в GitHub (без Git, через браузер) 1. Зайдите на [github.com](https://github.com) и войдите (или зарегистрируйтесь — бесплатно). 2. Нажмите **New repository** (зелёная кнопка). Назовите, например, `vershina-site`. Оставьте «Public» или «Private» — как хотите, для Vercel не важно. Нажмите **Create repository**. 3. На странице нового репозитория нажмите ссылку **uploading an existing file** (или «Add file» → «Upload files»). 4. Перетащите мышкой в это окно **все файлы и папки** из архива, который я прислал (`index.html`, `excursions.html`, `about.html`, `contacts.html`, `styles.css`, `app.js`, папку `api`, `package.json`, `.gitignore`). 5. Внизу нажмите **Commit changes**. Готово — код теперь в GitHub. --- ## Шаг 3. Импортируйте проект в Vercel 1. Зайдите на [vercel.com](https://vercel.com) → **Add New...** → **Project**. 2. Найдите в списке ваш репозиторий `vershina-site` → **Import**. 3. Никакие настройки трогать не нужно (Vercel сам поймёт, что это статический сайт с папкой `api`) — сразу нажимайте **Deploy**. 4. Подождите ~30 секунд — Vercel покажет «Congratulations!» и ссылку вида `vershina-site.vercel.app`. Сайт уже работает. --- ## Шаг 4. Добавьте переменные окружения (чтобы форма заявки заработала) Без этого шага сайт откроется и будет выглядеть нормально, но форма заявки будет показывать ошибку — ей нужны данные бота из Шага 1. 1. В проекте на Vercel: **Settings** → **Environment Variables**. 2. Добавьте две переменные: - `TELEGRAM_BOT_TOKEN` = токен бота из Шага 1 - `TELEGRAM_CHAT_ID` = chat id из Шага 1 3. Нажмите **Save**. 4. Перейдите во вкладку **Deployments**, откройте последний деплой → кнопка **⋯** → **Redeploy** (переменные окружения применяются только после пересборки). Теперь отправьте тестовую заявку через форму на сайте — она должна прийти вам в Telegram за пару секунд. --- ## Шаг 5. Подключите свой домен (необязательно) Если хотите открывать сайт по `вершина-тур.рф` (или любому своему домену), а не по `....vercel.app`: 1. **Settings** → **Domains** → введите свой домен → **Add**. 2. Vercel покажет 1-2 DNS-записи, которые нужно добавить у вашего регистратора домена (там, где вы его покупали — в панели управления DNS). 3. Подождите обновления DNS (обычно от нескольких минут до пары часов) — Vercel сам выпустит и настроит бесплатный SSL-сертификат, ничего дополнительно делать не нужно. --- ## Как обновлять сайт дальше Просто заходите в репозиторий на GitHub, открываете нужный файл (например, `index.html` или `app.js` — там же и список экскурсий), нажимаете значок карандаша («Edit»), правите текст прямо в браузере, нажимаете **Commit changes**. Vercel сам подхватит изменения и обновит сайт за ~30 секунд — ничего больше делать не нужно. Чтобы добавить/убрать экскурсию — открываете `app.js`, находите список `const routes = [...]` в начале файла, добавляете или удаляете строчку по образцу уже существующих. --- ## Если что-то не получается - **Форма пишет ошибку отправки** → проверьте Шаг 4: обе переменные заданы и был сделан Redeploy после их добавления. - **Не приходит в Telegram** → убедитесь, что вы писали боту первым (Шаг 1, пункт 3) — Telegram не разрешает ботам писать первыми. - **Не получается загрузить файлы в GitHub одним разом** → можно перетаскивать по несколько файлов за раз, GitHub объединит все загрузки в один коммит, если не нажимать Commit между ними. Если застряли на каком-то шаге — пришлите скриншот, разберёмся вместе.
